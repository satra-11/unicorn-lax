# ADR 002: 顔画像認識モデルの変更 (Arkface から dlib+ChineseWhisper へ)

## ステータス

承認済み (Accepted)

## 日付

2026-09-30

## コンテキスト

ADR 001にて、ブラウザ内で完結する写真選定ツールとして Arkface を採用していた。しかし、さらなる高精度な顔認識とクラスタリングを追求するため、モデルの変更を検討した。特に、子どもの顔の経年変化や様々な角度からの認識精度を向上させる必要があった。

## 決定事項

顔認識モデルおよびクラスタリング手法を、従来の Arkface から、`dlib` (顔検出・特徴量抽出) と `Chinese Whispers` アルゴリズム (クラスタリング) の組み合わせに変更する。

## 採用理由

1. **高精度な特徴量抽出**: `dlib` の顔認識モデルは非常に高い精度を誇り、類似人物の誤認を減らすことができる。
2. **クラスタリングアルゴリズムの最適化**: `Chinese Whispers` はクラスター数（人数）を事前に指定する必要がないグラフベースのクラスタリングアルゴリズムであり、未知の人数が含まれる写真群の自動分類に非常に適している。
3. **柔軟性と拡張性**: これらの技術は堅牢であり、今後の機能拡張（年齢変化への対応など）に対しても柔軟に対応可能である。

## 影響・結果

- **バックエンド/ワーカーへの影響**: ブラウザ単体での実行が困難になる場合、Python (WASMまたはローカルサーバー) との連携が必要になる可能性がある。本プロジェクトではどのように統合するかを今後詳細に決定する。
- **パフォーマンス**: 処理の負荷が高まる可能性があるため、バッチ処理や非同期処理の最適化が求められる。
